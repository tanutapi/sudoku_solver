# Sudoku Solver

My Sudoku Solver implemented in Python — a backtracking solver with no
external dependencies.

## Usage

```
python sudoku_solver.py
```

The puzzle to solve is the `PUZZLE` list at the top of
`sudoku_solver.py`, written row by row with `0` marking an empty cell.
Edit it to solve a different board. If the board has no solution, the
program says so instead of printing a board.

## Tests

```
python -m unittest
```
